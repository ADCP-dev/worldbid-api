## Convenciones (de AGENTS.md + skills)

**Backend:**
- NUNCA escribir entity/service/controller/DTO a mano → usar Hygen generators
- NUNCA hardcodear migraciones → solo `pnpm migration:generate` + `pnpm migration:run`
- NUNCA `console.log` → usar NestJS Logger
- SIEMPRE path aliases: `@iam/*`, `@users/*`, `@infra/*`, `@src/*`, `@ext/*`
- Tablas en extensiones: prefijo `ext_<name>_`
- NUNCA rutas relativas largas (`../../../`)

**Frontend:**
- SIEMPRE usar componentes `@base/ui-app/` — NUNCA custom si ya existe uno base
- NUNCA escribir forms/tables desde cero — usar componentes base
- SIEMPRE path aliases: `@/`, `@base`, `@cms`, `@landing`
- NUNCA `console.log` — usar `vue-sonner` toast
- Forms con Zod + componentes base
- DataTables con TanStack Vue Table

**TypeScript:**
- `import type` para types only
- Never `any` → `unknown` + guards
- Asumir null/undefined siempre
- No hardcodear env, usar config
