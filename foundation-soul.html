El Alma Metodológica: SDD

  • • Spec-Driven Development con 7 fases obligatorias
  • • proposal → spec → design → tasks → apply → verify → archive
  • • 16 skills (sub-agentes), 3 commands, persistencia configurable
  • • OpenCode como orquestador con deepseek-v4-pro
  • • MCPs como herramientas: context7, engram, tavily, postgres, stripe, playwright
  • • Filosofía: delegar primero, parar siempre, cero anti-patrones

El Alma Técnica: Convención sobre Código

  • • Hygen generators — NUNCA entity/service/controller/DTO a mano
  • • Migraciones — solo generate + run, nunca SQL inline
  • • UI kit @base/ui-app/ — siempre reusar, nunca custom
  • • Path aliases — @iam/*, @users/* (back); @/, @base, @cms (front)
  • • Extensions — prefijo ext_<name>_ en tablas
  • • Logger — NestJS Logger / vue-sonner, nunca console.log
